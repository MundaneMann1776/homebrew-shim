# MundaneMann1776 Shim

## How do I install these formulae?

`brew install mundanemann1776/shim/<formula>`

Or `brew tap mundanemann1776/shim` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mundanemann1776/shim"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
